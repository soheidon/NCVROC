# NCVROC Git-Release project profile

When using the `git-release` skill or performing release work for this repository,
apply these project-specific defaults to supplement and customize the global profile.

## Repository and project identity

- Repository: `soheidon/NCVROC`
- Release author: Sohei Ide (`@soheidon`)
- Co-authors: none
- Contributors credited in new release metadata: none

## Release defaults

- Release notes language: English
- Formal R-package assets: `NCVROC_X.Y.Z.tar.gz` and `NCVROC_X.Y.Z.pdf`
- Stage release assets in the project's `Release` directory rather than adding build artifacts to the source tree.

The requested version, branch, tag, and release target must still be resolved
from the current repository and the user's instruction.
